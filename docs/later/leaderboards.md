# Future leaderboards and seasons

Leaderboards and seasons are not part of the MVP.

Possible later scoring categories:

- Fastest first automation.
- Most ore generated during a season.
- Fewest API calls to reach a goal.
- Most reliable bot over a fixed window.
- Best starter-client extension or dashboard.

Guardrail: scoring should reward programming skill and strategy, not workspace spend or brute-force polling.
