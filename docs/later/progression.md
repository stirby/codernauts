# Future progression ideas

Current progression is miners, claims, and crusher tiers. Deeper systems belong here until promoted.

## Prestige: the gravel is never fine enough

The prestige fiction is reserved and already named: "the gravel is never fine enough." Crush your own infrastructure for a permanent yield multiplier, then rebuild. Announce each prestige reset with "Gravel standards have been revised."

## Conversion-unlock gating

Crusher tiers gate which resources can be crushed today. Later gating could go further: per-resource process unlocks, research-style prerequisites, or one-time gravelization permits for exotic finds.

## The object that resists

Exactly one ungravelizable object exists somewhere. Cracking it is a season finale, not a regular mechanic. Do not build it until a season needs a finale.

## Other parked ideas

- Outpost upgrades beyond the crusher.
- Scanner upgrades.
- Automation modules.
- Bot challenge milestones.

Guardrails: progression should create reasons to write better software, not just require more clicking. Every name must pass the trash-talk naming test in `docs/mvp/scaling.md`.
