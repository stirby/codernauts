# Codernauts

Codernauts is a planning workspace for an asynchronous multiplayer idle strategy game built around Coder workspaces.

The gameplay plan lives in [`docs/`](docs/). Start with [`docs/README.md`](docs/README.md), then review [`docs/13-open-questions.md`](docs/13-open-questions.md) for all `[REVIEW]` decisions.
